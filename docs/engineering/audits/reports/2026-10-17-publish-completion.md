# Publish acceptance continuation — October 17, 2026

This pass closes the interrupted-save, larger structured-book, cross-book warning,
and broader wizard-output gaps from the preceding Publish reports. It delivers
verified fixes, not a public release or an exhaustive certification of every
platform and template permutation. Overall Publish acceptance remains open for
the native interaction checks listed below. The owner approved hiding
inapplicable scene controls; that follow-up is implemented and verified.

## Confirmed problems corrected

- **False settings-save success.** The installed Obsidian implementation catches
  JSON write errors and resolves `Plugin.saveData()`. A real denied-write test
  therefore closed the wizard and reported success while settings stayed old
  and the template changed. Verify the exact persisted settings snapshot after
  `saveData`; propagate failure through the existing save queue and notification.
  This verification covers all plugin settings saves, not only Publish.
- **Partial wizard saves.** Restore the existing layout and generated template
  if settings persistence fails. Failed new registrations remove only their
  newly generated file through FileManager's trash operation. Block writes in a
  settings-recovery session. Capture edited values before waiting, and preserve
  a newer external template edit when rolling back our own generated bytes.
- **Stale or incorrectly resolved imports.** Re-read the actual selected file
  at final Save; reject a deleted/emptied file and case-invalid `$BODY$`.
  Preserve the selected vault path rather than compacting it into an ambiguous
  root-relative path. Read external files live and use Electron's public
  `webUtils.getPathForFile` API for dropped files. Failed settings writes roll
  back registration and leave the importer open for retry.
- **Editable names selected legacy formatting.** Designed-style labels that
  contain legacy template names must still follow their own structural spec.
- **Controls did not reach the PDF.** Honor custom even/odd header corners when
  no named header preset is selected; use a dedicated chapter running-title
  value; retain bottom-center folios when headers are off; honor explicit Arabic
  frontmatter folios, Word/Arabic Part labels, and dedicated-opener spacing.
  Slider/default labels now describe the renderer's actual initial values.
- **Literal dollars broke Pandoc templates.** Escape custom header/separator
  dollars through both Pandoc-template parsing and LaTeX. Actual compilation
  exercises dollar, ampersand and hash characters.
- **Incorrect structural warnings.** Carry authored Part-marker paths through
  scene selection and range validation. Settings also measures book-wide Part
  markers. Export warnings use the selected source book's epigraphs rather than
  the active timeline book's epigraphs.
- **Book Details failures stuck the editor.** Surface file-write failures and
  always release the busy state, allowing retry without reopening Settings.
- **Book Pages showed stale contents.** Refresh the resolved page list after
  Book Details add/reset. Reflect a confirmed `Enabled` write immediately while
  metadata cache catches up, show write failures, and retain recovery controls.
  Discard superseded asynchronous preview renders.
