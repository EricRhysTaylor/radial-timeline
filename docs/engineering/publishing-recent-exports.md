# Recent exports

After an export, RT checks that the expected files exist and their basic format can be read. **Open file** is the main next step. These checks do not assess every page or approve manuscript content.

To reopen an earlier file, choose **Recent exports** from the export dialog header or Destination. The list shows the five latest export jobs with dates, formats and links to each final file. Split exports keep their parts together. PDF and Markdown open in Obsidian; Word opens through the system document app.

Choose **Details** for file checks and the recorded source selection/export choices. **Optional sign-off** lets you mark each final file after inspecting it and save that confirmation. It is not required to export or open a file. Sign-off belongs to the checked version of the files and does not count after their bytes change.

The list survives closing the dialog and restarting Obsidian. It uses the portable receipts saved beside exports, plus a small settings index of recent receipt paths. Existing receipts in the known export destinations are discovered automatically. Missing files or unreadable records are reported. This list reopens delivered files; restoring an old setup is a separate operation and is not offered here.
