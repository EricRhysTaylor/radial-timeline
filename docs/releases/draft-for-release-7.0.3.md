## Radial Timeline 7.0.3

Exporting a manuscript to PDF or Word could fail with a missing font error. This release fixes that.

### Fixes

- **PDF and Word export** — the fonts and the Word reference document now come with the plugin, so export works without any setup. Thanks to **@therisingtithes** ([#34](https://github.com/EricRhysTaylor/Radial-Timeline/issues/34)).
- **Font status** — Publish and Export now show which fonts are actually available, and a failed export tells you which font caused it.
