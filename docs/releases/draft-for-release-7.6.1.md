## Fixes and improvements

- PDF styles save reliably and apply custom page sizes, typography, headers, page numbers, Chapters, and Parts.
- PDF exports check manuscript text coverage.
- Publishing controls show options relevant to the selected formatting.
- Settings and Book Details report save failures and support retry.
- Planetary time edits preserve the selected hour and minute.
- Local model discovery supports cancellation, timeouts, and response-size limits.
- Smaller plugin bundle, updated dependencies, and interface compatibility improvements.
