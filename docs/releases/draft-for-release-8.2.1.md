## Radial Timeline 8.2.1

Two fixes for Book from Community.

### Fixes

- **Book from Community folder:** when every folder name Radial Timeline would offer for the book is already taken, it now offers the book's plain name and explains the problem, so Obsidian stays responsive.
- **Book from Community dismiss:** if Obsidian can't save the plugin's data when you dismiss a cancelled transfer, the card or dialog stays open with the record kept, so you can try again.
