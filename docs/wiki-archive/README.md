# Wiki image archive

Images that no wiki page uses any more, moved out of `wiki/images/` on 24 Oct 2026 so they stop publishing to the GitHub wiki. Nothing was deleted.

Older release notes still show some of these images through raw GitHub URLs pinned to earlier commits or the `master` branch, and those URLs keep working. If a page needs one again, move it back to `wiki/images/`.

On 13 Nov 2026, 22 more images moved here when their pages stopped using them. These were dialogs and panels whose sections already describe them in words, several of them out of date (such as the old Timeline search dialog), plus duplicate shots. The docs site (docs.radialtimeline.com) shows its own live mockups for some interface pieces.
