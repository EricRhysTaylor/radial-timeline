A free, fully analyzed demo vault built around Jane Austen's *Pride & Prejudice*. All 61 chapters are scene notes with full properties, alongside 15 Save the Cat beat notes, 28 character notes, and saved AI analysis you can read without an API key: Pulse analysis on every chapter, four Gossamer signals, and three Inquiry sessions. It's the fastest way to see what Radial Timeline produces from a full-length novel.

## How to get it

The demo vault is a direct download. No signup or API key needed.

1.  Click **Get the free demo vault** on the plugin's Welcome screen, or **View demo & download** under **Settings → PRO → Demo vaults**. Both open the [download page](https://www.radialtimeline.com/resources/free) on radialtimeline.com.
2.  Click **Download Demo Vault**.

## How to install it

1.  Unzip the download. You'll get a folder named **Pride & Prejudice Demo Vault**.
2.  In Obsidian, choose **Open another vault → Open folder as vault** and select that folder.
3.  Turn on community plugins when Obsidian asks, then install **Radial Timeline** from **Settings → Community plugins → Browse**.
4.  The **Welcome screen** opens with the plugin. It detects the packaged book and shows **Open the sample vault**. Click it to drop straight into the finished story on the timeline. (If you skip the Welcome screen, point the plugin at the book yourself under **Settings → Core → Books**, then open the view with **Radial timeline: Open**.)

The download holds the book and its notes only, with no Obsidian settings or plugin files. You install the current plugin yourself in step 3.

## What's inside

*   **`Pride & Prejudice/`** — the novel as 61 chapter notes plus 15 Save the Cat beat notes. Every chapter carries full properties (`Act`, `When`, `Duration`, `Synopsis`, `Subplot`, `Character`, `POV`, `Status`, `Publish Stage`, and more) and a saved **Pulse** analysis. The beat notes hold four Gossamer signals: momentum, tension, activity, and interiority.
*   **`Characters/`** — notes for 28 characters, linked from every chapter they appear in.
*   **`Radial Timeline/Inquiry/`** — three saved Inquiry sessions, ready to read in the [Inquiry view](Inquiry).
*   **`Source Manuscript/`** — the public-domain text of the novel and a plain-text synopsis.
*   **`Welcome`**, **`README`**, **`Chronology`**, and **`Story Structure`** — short guides to the vault and its editorial choices.

## Exploring it

*   Switch modes with `1` (Progress), `2` (Narrative), `3` (Chronologue), `4` (Gossamer) and hover any scene for its synopsis and Pulse analysis.
*   Try Chronologue's **Shift** sub-mode to see elapsed time between scenes across the novel's calendar.
*   Open the [Inquiry view](Inquiry) to read the saved sessions. Inquiry opens with AI turned off, so every saved answer is readable without an API key. To run new questions, turn on AI and set up a cloud provider or a validated Local LLM in **Settings → AI**.
